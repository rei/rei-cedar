# Cedar Foundations

This section presents Cedar's design foundations — the rules and tokens that
sit underneath every component. It is the Storybook face of
[`docs/FOUNDATIONS.md`](../../../docs/FOUNDATIONS.md) (in progress — see
`docs/tickets/foundations-principles-doc.md`), the normative principles doc
these pages will cite by section.

The structure follows the pattern proven in design-system audits: one
**Overview** and one **Tokens** page per foundation area, where the Overview
states the rules in human language and the Tokens page shows the actual
values the code enforces.

## The rule for these pages

Each page cites `FOUNDATIONS.md §n` for its rules the way component contracts
cite `docs/cedar-semantic-taxonomy.md` for vocabulary. Where a token table is
shown, it is generated from the shipped token surface — never hand-typed, so
docs cannot drift from code.

**Until FOUNDATIONS.md lands:** this section is a scaffold. Do not write
principles into these pages from memory; the doc is authored by humans and
signed off like an ADR (see the ticket for why).
